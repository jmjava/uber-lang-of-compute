# Theory: Physics Correspondences for the KBL Compute Fabric

This directory is the academic layer of the repository. Physics-shaped names are **nature-inspired abstractions**, in the same sense that a neural net is a brain-inspired abstraction: we copy a structure that nature already found useful, discard the wetware, and say which is which. We are not proving a physical theory.
